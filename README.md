# گالری طلا و جواهر — Gold Gallery

اپلیکیشن اندروید فروش طلا و جواهر با قابلیت صدور فاکتور، ساخته‌شده با Kotlin و Jetpack Compose.

An Android gold & jewelry shop app with invoicing, built with Kotlin and Jetpack Compose (Persian / RTL UI).

## امکانات

- **کاتالوگ محصولات**: انگشتر، گردنبند، دستبند، گوشواره، سرویس طلا و سکه با جستجو و فیلتر دسته‌بندی
- **قیمت‌گذاری خودکار طلا** بر اساس فرمول بازار ایران:
  `طلای خام + اجرت ساخت + ۷٪ سود فروشنده + ۹٪ مالیات بر ارزش افزوده`
- **نرخ روز طلا**: قیمت هر گرم طلای ۱۸ عیار از صفحه اصلی قابل ویرایش است و قیمت همه اقلام به‌صورت زنده به‌روز می‌شود (تبدیل خودکار به عیارهای ۲۱، ۲۲ و ۲۴)
- **صدور فاکتور**: انتخاب اقلام، ثبت مشخصات مشتری، شماره فاکتور خودکار، تاریخ شمسی
- **فاکتور PDF**: تولید فاکتور PDF با فونت وزیرمتن و چیدمان راست‌به‌چپ + اشتراک‌گذاری
- **مدیریت موجودی**: کسر خودکار از موجودی پس از صدور فاکتور
- **ذخیره‌سازی دائمی** با Room (محصولات و فاکتورها)
- **رابط کاربری فارسی و راست‌به‌چپ** با تم طلایی و پشتیبانی از حالت تاریک

## معماری

```
app/src/main/java/com/goldgallery/app/
├── data/            # Room (دایتابیس، DAO، موجودیت‌ها)، Repository، داده نمونه
├── logic/           # GoldCalculator (فرمول قیمت طلا)، JalaliDate (تاریخ شمسی)، PersianFormat (ارقام فارسی)
├── pdf/             # InvoicePdfGenerator — تولید PDF فاکتور با PdfDocument
├── ui/              # تم، ناوبری و صفحه‌ها (خانه، محصولات، فاکتور جدید، فاکتورها، جزئیات فاکتور)
└── viewmodel/       # ShopViewModel (StateFlow)
```

## ساخت و اجرا

پیش‌نیاز: JDK 17+ و Android SDK (platform 35)

```bash
./gradlew assembleDebug        # ساخت APK در app/build/outputs/apk/debug/
./gradlew testDebugUnitTest    # اجرای تست‌های واحد (محاسبات قیمت، تاریخ شمسی)
```

## نکات فنی

- حداقل نسخه اندروید: ۸٫۰ (API 26)
- فونت [وزیرمتن](https://github.com/rastikerdar/vazirmatn) (OFL) در رابط کاربری و PDF استفاده شده است
