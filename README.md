# زرین طلا — اپلیکیشن فروش طلا و جواهر با صدور فاکتور

اپلیکیشن اندروید بومی (Kotlin + Jetpack Compose) برای مدیریت فروش طلا و جواهر با رابط کاربری کاملاً فارسی و راست‌به‌چپ (RTL) و قابلیت **صدور فاکتور PDF**.

## قابلیت‌ها

- **داشبورد**: نمایش نرخ روز طلای ۱۸ عیار، فروش امروز، تعداد فاکتورها و کالاها و دسترسی سریع.
- **مدیریت کالا (انبار)**: افزودن/ویرایش/حذف کالا با وزن، عیار، اجرت، قیمت نگین، موجودی و دسته‌بندی (طلا، جواهر، سکه، آبشده، ست).
- **مدیریت مشتریان**: ذخیره نام، تلفن و آدرس مشتریان.
- **صدور فاکتور**: افزودن اقلام (از انبار یا دستی)، محاسبه خودکار ارزش طلا، اجرت، سود و مالیات بر ارزش افزوده، اعمال تخفیف و مبلغ نهایی.
- **فاکتور PDF**: ساخت فاکتور PDF فارسی و راست‌به‌چپ و اشتراک/مشاهده آن از طریق سایر برنامه‌ها.
- **تنظیمات**: نرخ روز طلا، مشخصات فروشگاه و درصد سود و مالیات.
- **ذخیره‌سازی محلی** با Room؛ داده‌ها روی دستگاه باقی می‌مانند.

## معماری

- **زبان/UI**: Kotlin، Jetpack Compose (Material 3)
- **معماری**: تک‌اکتیویتی + Navigation Compose، الگوی Repository و `AndroidViewModel`
- **پایگاه‌داده**: Room (کالا، مشتری، فاکتور، اقلام فاکتور، تنظیمات)
- **PDF**: `android.graphics.pdf.PdfDocument` با متن فارسی راست‌به‌چپ
- **تاریخ**: تبدیل میلادی به شمسی (جلالی) و ارقام فارسی

## منطق قیمت‌گذاری

برای هر قلم بر اساس نرخ روز طلای ۱۸ عیار:

```
ارزش طلا      = وزن × (نرخ روز × عیار / ۱۸)
اجرت          = ارزش طلا × درصد اجرت
سود           = (ارزش طلا + اجرت) × درصد سود
مالیات        = (اجرت + سود) × درصد مالیات
مبلغ هر واحد  = ارزش طلا + اجرت + نگین + سود + مالیات
```

## ساخت پروژه

```bash
# مسیر Android SDK را در local.properties تنظیم کنید: sdk.dir=/path/to/android-sdk
./gradlew :app:assembleDebug
```

خروجی: `app/build/outputs/apk/debug/app-debug.apk`

- `minSdk = 24`، `targetSdk = 34`
