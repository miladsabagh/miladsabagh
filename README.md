# طلایار — اپلیکیشن فروش طلا و جواهر

اپلیکیشن اندروید برای مدیریت فروشگاه طلا و جواهر با قابلیت صدور فاکتور PDF.

## ویژگی‌ها

### مدیریت محصولات
- ثبت محصولات طلا، جواهر، سکه و سایر اقلام
- محاسبه خودکار قیمت بر اساس وزن، عیار و اجرت ساخت
- پشتیبانی از قیمت ثابت برای جواهرات
- فیلتر بر اساس دسته‌بندی و جستجو

### فروش و صدور فاکتور
- سبد خرید با افزودن/کاهش تعداد
- انتخاب مشتری یا ثبت مشتری جدید
- محاسبه خودکار جمع، تخفیف و مالیات
- صدور فاکتور با شماره‌گذاری خودکار
- خروجی PDF و اشتراک‌گذاری

### مدیریت مشتریان
- ثبت نام، تلفن، کد ملی و آدرس
- جستجو و مدیریت لیست مشتریان

### داشبورد
- نمایش نرخ روز طلا
- آمار محصولات، مشتریان و فروش
- لیست آخرین فاکتورها

### تنظیمات
- اطلاعات فروشگاه (نام، آدرس، تلفن، پروانه)
- نرخ طلا روزانه
- درصد مالیات
- پیشوند شماره فاکتور

## معماری

```
app/
├── data/
│   ├── model/          # مدل‌های داده (Product, Customer, Invoice, ...)
│   ├── database/       # Room DB و DAOها
│   └── repository/     # لایه Repository
├── ui/
│   ├── theme/          # تم طلایی با Material 3
│   ├── navigation/     # Navigation Compose
│   ├── screens/        # صفحات UI
│   ├── components/     # کامپوننت‌های مشترک
│   └── viewmodel/      # ViewModelها
└── util/
    ├── GoldPriceCalculator.kt   # محاسبه قیمت طلا

```

## فرمول محاسبه قیمت طلا

```
ارزش طلا = وزن × ضریب عیار × نرخ هر گرم
اجرت = ارزش طلا × درصد اجرت / ۱۰۰
قیمت نهایی = ارزش طلا + اجرت
```

ضرایب عیار: ۲۴=۱.۰، ۲۲=۲۲/۲۴، ۲۱=۲۱/۲۴، ۱۸=۱۸/۲۴، ۱۴=۱۴/۲۴

## نصب و اجرا

### پیش‌نیازها
- Android Studio Hedgehog یا جدیدتر
- JDK 17
- Android SDK 34

### مراحل

1. پروژه را در Android Studio باز کنید
2. Gradle Sync را اجرا کنید
3. دستگاه اندروید یا Emulator را متصل کنید
4. Run را بزنید

```bash
# یا از خط فرمان (با Android SDK نصب‌شده):
./gradlew assembleDebug
```
