# اپلیکیشن اندروید فروش طلا و جواهر

یک اپ موبایل Expo/React Native برای فروش طلا و جواهر که کاتالوگ محصول، سبد خرید، محاسبه نرخ روز طلا، اجرت، سود فروشنده، مالیات، تخفیف و صدور فاکتور قابل کپی را پوشش می‌دهد.

## قابلیت‌ها

- رابط فارسی و راست‌به‌چپ برای فروشگاه طلا و جواهر
- کاتالوگ نمونه شامل انگشتر، گردنبند، دستبند و گوشواره
- تنظیم نرخ هر گرم طلا، درصد مالیات و تخفیف فاکتور
- محاسبه اجرت درصدی و اجرت ثابت به‌ازای هر گرم
- محاسبه سود فروشنده و مالیات روی اجرت و سود
- ثبت نام و شماره تماس مشتری
- صدور متن فاکتور و کپی آن برای ارسال در پیام‌رسان‌ها

## راه‌اندازی

```bash
npm install
npm start
```

برای اجرای اندروید:

```bash
npm run android
```

## تست

```bash
npm run typecheck
npm test
```

## ساختار مهم

- `App.tsx`: رابط موبایل و جریان فروش
- `src/lib/invoice.ts`: منطق محاسبه فاکتور
- `src/data/catalog.ts`: کاتالوگ نمونه محصولات
- `tests/invoice.test.ts`: تست‌های واحد محاسبات فاکتور
