# زرین — اپلیکیشن فروش طلا و جواهر

اپلیکیشن اندرویدی مدیریت فروش طلا و جواهر با قابلیت **صدور فاکتور PDF**، ساخته‌شده با Kotlin و Jetpack Compose. رابط کاربری کاملاً فارسی و راست‌چین با فونت وزیرمتن است.

## امکانات

- **قیمت روز طلا**: ثبت قیمت هر گرم طلای ۱۸ عیار و محاسبه خودکار قیمت همه محصولات
- **مدیریت محصولات**: ثبت کالا با دسته‌بندی (انگشتر، گردنبند، سکه و…)، عیار (۱۸/۲۱/۲۲/۲۴)، وزن، درصد اجرت ساخت و موجودی
- **مدیریت مشتریان**: دفترچه مشتری با نام، تلفن و آدرس
- **صدور فاکتور**: انتخاب مشتری، افزودن اقلام از محصولات یا به‌صورت دستی، اعمال تخفیف، کسر خودکار از موجودی و شماره‌گذاری خودکار فاکتور
- **خروجی PDF**: تولید فاکتور PDF راست‌چین با سربرگ فروشگاه و اشتراک‌گذاری آن
- **تاریخ شمسی**: نمایش و چاپ تاریخ هجری شمسی در کل اپ و فاکتورها
- **وضعیت پرداخت**: علامت‌گذاری فاکتورها به‌صورت پرداخت‌شده/نشده و فیلتر فهرست

## فرمول قیمت‌گذاری (عرف بازار طلای ایران)

```
بهای طلا   = وزن × قیمت هر گرم (تبدیل‌شده به عیار کالا)
اجرت ساخت  = بهای طلا × درصد اجرت
سود فروشنده = (بهای طلا + اجرت) × درصد سود
مالیات      = (اجرت + سود) × نرخ مالیات بر ارزش افزوده
قیمت نهایی  = بهای طلا + اجرت + سود + مالیات
```

مطابق قانون، مالیات بر ارزش افزوده فقط به اجرت و سود تعلق می‌گیرد و اصل طلا معاف است. نرخ مالیات و درصد سود پیش‌فرض در «تنظیمات فروشگاه» قابل تغییر است.

## ساختار فنی

| لایه | فناوری |
|---|---|
| زبان | Kotlin |
| رابط کاربری | Jetpack Compose + Material 3 |
| پایگاه داده | Room |
| تنظیمات | DataStore Preferences |
| ناوبری | Navigation Compose |
| تولید PDF | `android.graphics.pdf.PdfDocument` |
| حداقل اندروید | API 26 (اندروید ۸) |

## ساخت و اجرا

```bash
# ساخت APK دیباگ
./gradlew assembleDebug

# اجرای تست‌های واحد (موتور قیمت‌گذاری، اعداد فارسی، تقویم شمسی)
./gradlew testDebugUnitTest
```

خروجی APK در مسیر `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## ساختار پروژه

```
app/src/main/java/ir/zarrin/gold/
├── data/        # موجودیت‌های Room، DAOها، دیتابیس و DataStore
├── domain/      # موتور قیمت‌گذاری طلا (GoldPricing)
├── pdf/         # تولید فاکتور PDF
├── ui/          # صفحات Compose، ViewModel و تم
└── util/        # اعداد فارسی و تقویم شمسی
```
