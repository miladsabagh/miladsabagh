# زرنگار | اپلیکیشن اندروید فروش طلا و جواهر

اپلیکیشن اندروید بومی (Kotlin + Jetpack Compose) برای مدیریت فروش طلا و جواهر با قابلیت **صدور فاکتور** حرفه‌ای، مناسب طلافروشی‌ها و جواهرفروشی‌ها.

## امکانات

- **داشبورد**: نمایش نرخ روز طلا، فروش امروز، تعداد فاکتورها، مشتریان و کالاها.
- **مدیریت کالاها**: ثبت کالاهای طلا/جواهر با عیار، وزن، اجرت و سود پیش‌فرض، و موجودی انبار.
- **مدیریت مشتریان**: ثبت و جستجوی مشتریان با نام، شماره تماس، آدرس و کد ملی.
- **صدور فاکتور**: انتخاب مشتری (از لیست یا موقت)، افزودن اقلام از انبار یا به‌صورت دستی، محاسبه خودکار قیمت بر اساس فرمول رایج بازار طلا:
  - `قیمت پایه = وزن × نرخ هر گرم`
  - `اجرت = قیمت پایه × درصد اجرت`
  - `سود = (قیمت پایه + اجرت) × درصد سود`
  - `مالیات بر ارزش‌افزوده = (اجرت + سود) × درصد مالیات`
  - `جمع = قیمت پایه + اجرت + سود + مالیات`
- **خروجی PDF**: تولید فاکتور در قالب PDF با طراحی حرفه‌ای و امکان اشتراک‌گذاری/چاپ از طریق هر اپلیکیشنی (ایمیل، پیام‌رسان، چاپگر و ...).
- **تاریخ شمسی**: نمایش تاریخ فاکتورها به‌صورت شمسی (جلالی) با الگوریتم دقیق و تست‌شده.
- **پشتیبانی کامل از راست‌به‌چپ (RTL)** و فونت فارسی وزیرمتن (Vazirmatn).
- ذخیره‌سازی محلی با Room Database (بدون نیاز به اینترنت).

## تکنولوژی‌ها

- Kotlin, Jetpack Compose, Material 3
- Room (پایگاه داده محلی)
- Navigation Compose
- Kotlin Coroutines & Flow
- Android `PdfDocument` API برای تولید فاکتور PDF

## ساختار پروژه

```
app/src/main/java/ir/goldshop/app/
├── data/            # Entity ها، DAO ها، دیتابیس Room و Repository
├── domain/          # منطق محاسبه قیمت (PricingCalculator)
├── pdf/             # تولید فاکتور PDF
├── ui/              # صفحات Compose به تفکیک بخش (dashboard, products, customers, invoice, settings)
└── util/            # ابزارهای کمکی (اعداد فارسی، تاریخ شمسی)
```

## راه‌اندازی و اجرا

### پیش‌نیازها

- JDK 17+
- Android SDK (API 34) و Build Tools 34.0.0
- (اختیاری) Android Studio برای توسعه راحت‌تر

### دستورات

```bash
# تنظیم مسیر SDK در local.properties (در صورت نیاز)
echo "sdk.dir=/path/to/android-sdk" > local.properties

# ساخت نسخه دیباگ
./gradlew assembleDebug

# اجرای تست‌های واحد
./gradlew testDebugUnitTest

# نصب روی دستگاه/شبیه‌ساز متصل
./gradlew installDebug
```

فایل خروجی APK در مسیر `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

### حداقل نسخه اندروید پشتیبانی‌شده

- `minSdk = 24` (Android 7.0)
- `targetSdk = 34` (Android 14)

## تست‌های خودکار

منطق اصلی محاسبه قیمت، فرمت اعداد فارسی و تبدیل تاریخ میلادی به شمسی با تست واحد (JUnit) پوشش داده شده‌اند:

```bash
./gradlew testDebugUnitTest
```
