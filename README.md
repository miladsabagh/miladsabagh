# زرین — اپ فروش طلا و جواهر

یک نمونه اپلیکیشن موبایل فارسی و راست‌به‌چپ برای فروش طلا و جواهر، ساخته‌شده با Expo و React Native.

## قابلیت‌ها

- صفحه خانه با قیمت نمایشی طلا، دسته‌بندی‌ها و محصولات محبوب
- کاتالوگ قابل جستجو و فیلتر
- جزئیات شفاف وزن، عیار، اجرت و مالیات
- سبد خرید و محاسبه جمع سفارش
- صدور و نمایش فاکتور فارسی
- پروفایل، سفارش‌ها و فاکتورهای کاربر

## اجرا

```bash
npm install
npm run web
```

برای اجرای اندروید:

```bash
npm run android
```

## بررسی کیفیت

```bash
npm run typecheck
npm test
npm run build:web
```

> قیمت‌ها و اطلاعات مشتری در این پروژه نمایشی هستند.
