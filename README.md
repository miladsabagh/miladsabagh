# زرین‌فاکتور — اپلیکیشن اندروید فروش طلا و جواهر

اپلیکیشن موبایل اندروید برای فروشگاه‌های طلا و جواهر با قابلیت **صدور فاکتور**؛ کاملاً فارسی و راست‌چین،
با محاسبه خودکار قیمت بر اساس نرخ روز طلا، اجرت، سود و مالیات بر ارزش افزوده.

## امکانات

- **داشبورد**: نرخ روز طلای ۱۸ عیار (قابل ویرایش سریع)، فروش امروز، فروش ماه جاری، تعداد فاکتور و مانده طلب مشتریان
- **مدیریت کالا**: طلا، جواهر، سکه و نقره با عیار، وزن، اجرت ساخت، قیمت نگین، موجودی انبار و قیمت مقطوع
- **مدیریت مشتریان**: نام، تلفن، کد ملی و نشانی؛ قابل انتخاب هنگام صدور فاکتور
- **صدور فاکتور فروش**: افزودن قلم از انبار یا به‌صورت دستی، محاسبه لحظه‌ای قیمت، تخفیف قلم و تخفیف کل،
  روش پرداخت (نقدی، کارت‌خوان، کارت به کارت، نسیه)، ثبت پرداخت جزئی و مانده
- **خروجی PDF**: فاکتور A4 با جدول اقلام، ریز محاسبات، مبلغ به حروف و جای امضا؛ قابل **اشتراک‌گذاری** و **چاپ**
- **تقویم هجری شمسی** و **ارقام فارسی** در سراسر برنامه، با شماره‌گذاری ماهانه فاکتورها (مثال: `140505-001`)
- **واحد پول قابل انتخاب** (تومان یا ریال)؛ همه مبالغ در پایگاه داده به ریال ذخیره می‌شوند
- کارکرد کاملاً **آفلاین**؛ داده‌ها روی خود دستگاه در پایگاه داده Room نگهداری می‌شوند

## فرمول قیمت‌گذاری

مطابق رویه رایج بازار ایران:

```text
ارزش طلا = وزن × نرخ هر گرم (تعدیل‌شده با عیار) × تعداد
اجرت     = ارزش طلا × درصد اجرت
سود      = (ارزش طلا + اجرت) × درصد سود فروشنده
مالیات   = (اجرت + سود) × درصد مالیات بر ارزش افزوده
مبلغ قلم = ارزش طلا + اجرت + سود + نگین + مالیات − تخفیف
```

نرخ روز بر مبنای طلای **۱۸ عیار** وارد می‌شود و برای عیارهای دیگر به‌صورت `نرخ × عیار ÷ ۱۸` تعدیل می‌شود.
اقلام «قیمت مقطوع» (مانند سکه) اجرت و سود ندارند و در صورت نیاز می‌توان آن‌ها را از مالیات معاف کرد.

## ساختار پروژه

| مسیر | توضیح |
| --- | --- |
| `app/src/main/java/ir/zarin/faktor/core` | تقویم شمسی، ارقام فارسی، قالب‌بندی مبلغ و تبدیل عدد به حروف |
| `app/src/main/java/ir/zarin/faktor/domain` | موتور قیمت‌گذاری طلا و شماره‌گذاری فاکتور |
| `app/src/main/java/ir/zarin/faktor/data` | مدل‌ها، پایگاه داده Room، مخزن‌ها و تنظیمات (DataStore) |
| `app/src/main/java/ir/zarin/faktor/ui` | صفحه‌های Jetpack Compose و ViewModelها |
| `app/src/main/java/ir/zarin/faktor/pdf` | رسم صفحه فاکتور، ساخت PDF، اشتراک‌گذاری و چاپ |

## ساخت و اجرا

نیازمندی‌ها: JDK ۱۷ یا بالاتر و Android SDK با `compileSdk 35`.

```bash
# ساخت نسخه دیباگ
./gradlew :app:assembleDebug

# ساخت نسخه انتشار (کوچک‌سازی با R8)
./gradlew :app:assembleRelease

# اجرای همه تست‌ها
./gradlew :app:testDebugUnitTest

# تولید تصاویر صفحه‌ها و پیش‌نمایش فاکتور
./gradlew :app:recordRoborazziDebug
```

خروجی‌ها:

- فایل APK: `app/build/outputs/apk/`
- تصاویر صفحه‌های برنامه: `app/build/outputs/screenshots/`
- پیش‌نمایش صفحه فاکتور A4: `app/build/outputs/invoice-preview/`

کمترین نسخه پشتیبانی‌شده اندروید: **۷.۰ (API 24)**.

## تست‌ها

- تست موتور قیمت‌گذاری، تقویم شمسی، ارقام فارسی، مبلغ به حروف و شماره‌گذاری فاکتور
- تست یکپارچه پایگاه داده Room برای صدور فاکتور، کاهش موجودی انبار و گزارش فروش
- تست تصویری صفحه فاکتور A4 و صفحه‌های اصلی برنامه (Robolectric + Roborazzi)
