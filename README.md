# گالری میلاد صباغ

یک اپلیکیشن موبایل اندروید برای فروش طلا و جواهر که با Expo و React Native ساخته شده است.

## قابلیت‌ها

- رابط فارسی راست‌به‌چپ با تم طلایی و کارت‌های محصول
- ثبت قیمت روز هر گرم طلای ۱۸ عیار
- انتخاب تعداد کالاها و ساخت سبد خرید
- محاسبه طلای خام، اجرت ساخت، سود فروشنده، مالیات و مبلغ نهایی
- صدور متن فاکتور و اشتراک‌گذاری آن با قابلیت Share اندروید

## اجرای پروژه

```bash
npm install
npm run android
```

برای اجرای تست‌های محاسبه فاکتور:

```bash
npm test
```
