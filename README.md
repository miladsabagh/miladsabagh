# اپلیکیشن فروش طلا و جواهر میلاد

اپلیکیشن موبایل اندروید برای فروش طلا و جواهر با قابلیت **صدور فاکتور** و محاسبه‌ی خودکار قیمت بر اساس قیمت روز طلا، وزن، عیار، اجرت، سود و مالیات بر ارزش افزوده.

ساخته‌شده با **React Native (Expo)** و **TypeScript**. رابط کاربری کاملاً فارسی و راست‌به‌چپ (RTL) با اعداد و واحد پول فارسی.

## امکانات

- **داشبورد**: نمایش قیمت روز طلای ۱۸ عیار، فروش کل، تعداد فاکتورها، موجودی و فاکتورهای اخیر.
- **مدیریت کالاها**: افزودن، ویرایش و حذف کالا (طلا، سکه، جواهر) با وزن، عیار، درصد اجرت و موجودی.
- **صدور فاکتور**: انتخاب کالاها با تعیین تعداد، ثبت مشخصات مشتری، اعمال تخفیف و محاسبه‌ی زنده‌ی مبلغ نهایی.
- **فاکتور رسمی**: نمایش فاکتور با سربرگ فروشگاه، تاریخ شمسی، ریز اقلام و جمع‌بندی مالی.
- **تاریخچه فاکتورها**: جستجو و مشاهده‌ی فاکتورهای صادرشده.
- **تنظیمات**: قیمت روز طلا، درصد سود، درصد مالیات و اطلاعات فروشگاه.
- **ذخیره‌سازی محلی**: تمام داده‌ها روی دستگاه با `AsyncStorage` ذخیره می‌شود.

## فرمول محاسبه فاکتور

برای هر قلم کالا:

```
قیمت هر گرم (بر اساس عیار) = قیمت گرم ۱۸ عیار × (عیار ÷ ۱۸)
ارزش طلا = وزن × قیمت هر گرم × تعداد
اجرت     = ارزش طلا × درصد اجرت
سود      = (ارزش طلا + اجرت) × درصد سود
مالیات   = (اجرت + سود) × درصد مالیات بر ارزش افزوده
جمع قلم  = ارزش طلا + اجرت + سود + مالیات
```

مبلغ نهایی فاکتور = جمع اقلام − تخفیف.

> مالیات بر ارزش افزوده مطابق قانون فقط روی اجرت و سود اعمال می‌شود، نه روی ارزش طلای خام.

## اجرا

```bash
npm install

# اجرای وب (برای پیش‌نمایش)
npm run web

# اجرای روی اندروید (نیازمند Android SDK / دستگاه یا شبیه‌ساز)
npm run android
```

برای ساخت فایل نصبی اندروید (APK/AAB) از [EAS Build](https://docs.expo.dev/build/introduction/) استفاده کنید:

```bash
npx eas build -p android --profile preview
```

## ساختار پروژه

```
App.tsx                     ناوبری اصلی، سربرگ و مدیریت RTL
src/
  theme.ts                  رنگ‌ها، فاصله‌ها و شعاع گوشه‌ها
  types.ts                  مدل‌های داده (کالا، فاکتور، تنظیمات)
  utils/
    format.ts               تبدیل اعداد و قالب‌بندی پول فارسی
    jalali.ts               تبدیل تاریخ میلادی به شمسی
    calc.ts                 منطق محاسبه فاکتور طلا
  storage/
    seed.ts                 داده‌های اولیه
    db.ts                   ذخیره‌سازی محلی (AsyncStorage)
  context/AppContext.tsx    مدیریت وضعیت سراسری
  components/               کامپوننت‌های مشترک و رسید فاکتور
  screens/                  صفحات اپلیکیشن
```
