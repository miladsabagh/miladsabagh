# زرین — اپلیکیشن اندروید فروش طلا و جواهر

اپلیکیشن موبایل اندروید برای فروشگاه‌های طلا و جواهر با قابلیت **صدور فاکتور**، کاتالوگ کالا، نرخ طلا و اشتراک‌گذاری PDF.

## قابلیت‌ها

- **خانه**: برند زرین، نرخ طلای ۱۸ عیار، دسترسی سریع و آخرین فاکتورها
- **کاتالوگ**: انگشتر، گردنبند، دستبند، گوشواره، سکه، شمش و سرویس با فیلتر و جستجو
- **صدور فاکتور**: انتخاب مشتری، افزودن اقلام، تخفیف، مالیات ۹٪ و ثبت فاکتور
- **سوابق**: لیست فاکتورهای صادرشده
- **جزئیات فاکتور**: مشاهده کامل و **اشتراک‌گذاری PDF**
- **تنظیم نرخ**: به‌روزرسانی قیمت پایه هر گرم طلای ۱۸ عیار
- رابط کاملاً **فارسی و راست‌به‌چپ (RTL)**
- ذخیره‌سازی محلی با **Room**

## اجرا

1. پروژه را در **Android Studio** (Hedgehog یا جدیدتر) باز کنید.
2. SDK 35 و JDK 17 را تنظیم کنید.
3. روی دستگاه یا شبیه‌ساز اندروید Run بگیرید.

```bash
./gradlew :app:assembleDebug
```

## ساختار

```
app/src/main/java/com/zarin/gold/
  data/          # مدل‌ها، Room، Repository
  ui/            # تم، کامپوننت‌ها، صفحات، ناوبری
  util/          # فرمت فارسی و خروجی PDF فاکتور
```

## محاسبه فاکتور

برای هر قلم:

`ارزش طلا = وزن × قیمت هر گرم (نسبت به عیار) × تعداد`  
`اجرت = ارزش طلا × درصد اجرت`  
`جمع قلم = ارزش طلا + اجرت + سنگ`  
`مالیات = (جمع − تخفیف) × ۹٪`
