# زرّین — اپلیکیشن اندروید فروش طلا و جواهر با صدور فاکتور

اپلیکیشن بومی اندروید (Kotlin + Jetpack Compose) برای مدیریت فروش طلا و جواهر و **صدور فاکتور رسمی**
با محاسبه‌ی خودکار ارزش طلا، اجرت ساخت، سود فروشنده و مالیات بر ارزش افزوده.
تمام رابط کاربری فارسی و راست‌به‌چپ است و تاریخ‌ها شمسی هستند.

---

## امکانات

### صدور فاکتور
- فاکتور **فروش** و **خرید** با شماره‌گذاری خودکار در هر سال شمسی (مثلاً `1403-0007`).
- انتخاب مشتری از دفتر مشتریان یا ثبت سریع مشتری جدید.
- افزودن اقلام از انبار با یک لمس، یا ساخت قلم دستی با پیش‌نمایش زنده‌ی محاسبات.
- ثبت تخفیف، بیعانه/پرداختی، روش پرداخت و توضیحات؛ محاسبه‌ی خودکار مانده بدهی.
- انتخاب تاریخ فاکتور با تقویم شمسی.

### خروجی فاکتور
- **PDF** در قطع A4 با چیدمان راست‌به‌چپ، جدول اقلام، جمع‌بندی، مبلغ به حروف و محل امضا.
- **چاپ** مستقیم از طریق سرویس چاپ اندروید.
- **ارسال متنی** فاکتور برای واتساپ، پیامک یا هر برنامه‌ی دیگر.

### مدیریت فروشگاه
- انبار کالا: نام، کد، نوع، عیار، وزن، اجرت، سود، قیمت نگین، موجودی و قیمت روز محاسبه‌شده.
- دفتر مشتریان: نام، تلفن، کد ملی، نشانی و یادداشت.
- داشبورد: نرخ روز طلا، فروش امروز و این ماه، مانده طلب و آخرین فاکتورها.
- گزارش فروش در بازه‌های امروز / این ماه / امسال / کل به همراه مشتریان برتر.
- تنظیمات فروشگاه: مشخصات، نرخ روز طلای ۱۸ عیار، درصد اجرت و سود پیش‌فرض، نرخ مالیات،
  واحد پول (تومان/ریال) و متن پایین فاکتور.

## فرمول قیمت‌گذاری

برای هر قلم فاکتور:

```
ارزش طلا      = وزن × نرخ هر گرم عیار همان قلم
اجرت ساخت     = درصدی از ارزش طلا، یا مبلغ ثابت هر گرم، یا مبلغ مقطوع
سود فروشنده   = درصدی از (ارزش طلا + اجرت)
مالیات        = درصد مالیات × پایه‌ی مالیاتی
مبلغ قلم      = ارزش طلا + اجرت + سود + قیمت نگین + مالیات
```

پایه‌ی مالیاتی بر اساس نوع کالا انتخاب می‌شود:

| نوع کالا | پایه‌ی مالیات |
| --- | --- |
| طلای ساخته‌شده | فقط «اجرت + سود» |
| سکه و طلای آبشده | معاف |
| نقره، جواهر و خدمات | کل مبلغ |

نرخ هر عیار از نرخ روز طلای ۱۸ عیار (۷۵۰) محاسبه می‌شود: `نرخ عیار = نرخ ۱۸ عیار × عیار ÷ ۷۵۰`.

## معماری

```
app/src/main/java/ir/zarrin/goldshop/
├── core/            تقویم شمسی، تبدیل ارقام فارسی، قالب‌بندی مبلغ و تبدیل عدد به حروف
├── domain/          مدل‌های دامنه و موتور محاسبه‌ی قیمت (GoldCalculator)
├── data/            Room (کالا، مشتری، فاکتور، اقلام) و DataStore برای تنظیمات
├── export/          ساخت PDF با PdfDocument، اشتراک‌گذاری و چاپ
└── ui/              Jetpack Compose (Material 3) — داشبورد، فاکتورها، انبار، مشتریان، گزارش، تنظیمات
```

- **زبان:** Kotlin ۲.۰
- **رابط کاربری:** Jetpack Compose + Material 3، فونت وزیرمتن، چیدمان RTL سراسری
- **پایگاه داده:** Room (آفلاین، بدون نیاز به اینترنت)
- **تنظیمات:** DataStore Preferences
- **حداقل نسخه اندروید:** ۷.۰ (API 24) — هدف: API 35

## ساخت پروژه

```bash
# مسیر Android SDK را در local.properties تنظیم کنید یا متغیر ANDROID_HOME را ست کنید
./gradlew assembleDebug        # ساخت فایل APK دیباگ
./gradlew testDebugUnitTest    # اجرای تست‌های واحد
```

خروجی APK در مسیر `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## تست‌ها

تست‌های واحد منطق حساس اپلیکیشن را پوشش می‌دهند:

- `GoldCalculatorTest` — محاسبه‌ی اجرت، سود، مالیات، سکه‌ی معاف، تخفیف و جمع فاکتور.
- `PersianCalendarTest` — تبدیل تاریخ میلادی/شمسی، سال کبیسه و طول ماه‌ها.
- `PersianNumbersTest` — ارقام فارسی، جداکننده‌ی هزارگان، تجزیه‌ی ورودی و تبدیل عدد به حروف.
