# جواهریار (GoldShop)

اپلیکیشن اندروید بومی برای مدیریت فروش طلا و جواهر با قابلیت صدور، ذخیره، اشتراک‌گذاری و چاپ فاکتور.

## امکانات

- **مدیریت کالا (انبار):** ثبت انگشتر، گردنبند، دستبند، گوشواره، سکه، شمش و ... به همراه وزن، عيار، درصد اجرت ساخت، درصد سود فروشنده، قیمت سنگ و موجودی.
- **مدیریت مشتریان:** ثبت نام، شماره تماس، آدرس و کد ملی مشتریان و انتخاب سریع آن‌ها هنگام صدور فاکتور.
- **نرخ روز طلا:** ثبت و به‌روزرسانی نرخ هر گرم طلای ۱۸ عيار همراه با تاریخچه.
- **صدور فاکتور:** افزودن اقلام از انبار یا به‌صورت دستی، محاسبه خودکار قیمت بر اساس فرمول رایج طلافروشی‌های ایران:
  - `ارزش طلا = وزن × نرخ روز (متناسب با عيار)`
  - `اجرت ساخت = ارزش طلا × درصد اجرت`
  - `سود فروشنده = (ارزش طلا + اجرت) × درصد سود`
  - `مالیات ارزش‌افزوده = (اجرت + سود) × درصد مالیات` (طبق قانون، مالیات فقط بر اجرت و سود تعلق می‌گیرد، نه بر اصل طلا)
  - امکان اعمال تخفیف، ثبت مبلغ پرداختی و مانده حساب.
- **خروجی فاکتور:** تولید فایل PDF فارسی (راست‌به‌چپ) با هدر فروشگاه، اشتراک‌گذاری از طریق هر اپلیکیشنی و همچنین چاپ مستقیم با استفاده از سیستم چاپ اندروید.
- **گزارش فروش:** جمع فروش و وزن فروش‌رفته امروز، ۷ روز اخیر و ماه جاری.
- **تنظیمات فروشگاه:** نام، آدرس، تلفن فروشگاه و مقادیر پیش‌فرض اجرت/سود/مالیات.

## پشته فناوری

- Kotlin + Jetpack Compose (Material 3) برای رابط کاربری کاملاً راست‌به‌چپ (RTL) فارسی
- Room برای پایگاه‌داده محلی (کالاها، مشتریان، فاکتورها، تاریخچه نرخ طلا)
- Jetpack DataStore برای تنظیمات فروشگاه
- Navigation Compose برای مسیریابی بین صفحات
- `android.graphics.pdf.PdfDocument` + `android.text.StaticLayout` برای تولید صحیح PDF با متن فارسی راست‌به‌چپ
- `android.print` API برای چاپ مستقیم فاکتور

نیازی به فریم‌ورک تزریق وابستگی (Hilt/Koin) نیست؛ یک `ViewModelProvider.Factory` سبک در `ui/AppViewModelFactory.kt` این کار را انجام می‌دهد.

## ساختار پروژه

```
app/src/main/java/com/miladsabagh/goldshop/
├── data/
│   ├── local/          # Room entities, DAOs, Database
│   ├── repository/     # GoldShopRepository (لایه دسترسی به داده)
│   └── settings/       # SettingsRepository (DataStore)
├── pdf/                 # تولید و چاپ فاکتور PDF
├── ui/
│   ├── home/            # داشبورد
│   ├── products/        # مدیریت کالا
│   ├── customers/       # مدیریت مشتری
│   ├── invoice/         # صدور فاکتور، لیست فاکتورها، جزئیات فاکتور
│   ├── reports/         # گزارش فروش
│   ├── settings/        # تنظیمات فروشگاه
│   ├── navigation/       # ناوبری بین صفحات
│   └── theme/            # تم و رنگ‌بندی طلایی
└── util/                 # فرمول قیمت‌گذاری، فرمت اعداد فارسی، تقویم شمسی
```

## ساخت پروژه (Build)

پیش‌نیاز: JDK 17+ و Android SDK (compileSdk 34، minSdk 26).

```bash
./gradlew :app:assembleDebug      # ساخت APK دیباگ
./gradlew :app:testDebugUnitTest  # اجرای تست‌های واحد (فرمول قیمت، فرمت اعداد، تقویم شمسی)
```

فایل `local.properties` (که در گیت نادیده گرفته می‌شود) باید مسیر Android SDK را مشخص کند:

```
sdk.dir=/path/to/Android/sdk
```

## تست‌های خودکار

منطق حساس به خطا (فرمول قیمت‌گذاری طلا، تبدیل تاریخ میلادی به شمسی، فرمت اعداد فارسی) با تست واحد JUnit پوشش داده شده و بدون نیاز به شبیه‌ساز اندروید روی JVM اجرا می‌شود:

- `PriceCalculatorTest` — صحت محاسبه ارزش طلا، اجرت، سود، مالیات (فقط روی اجرت و سود)، تعداد و قیمت سنگ.
- `PersianFormatTest` — تبدیل ارقام فارسی/انگلیسی و قالب‌بندی مبلغ و وزن.
- `JalaliDateTest` — صحت تبدیل تاریخ میلادی به شمسی (اعتبارسنجی‌شده در برابر کتابخانه مرجع `jdatetime`).
