# زرفام — اپلیکیشن فروش طلا و جواهر

اپلیکیشن اندرویدی مدیریت فروش طلا و جواهر با قابلیت صدور فاکتور PDF، ویژه طلافروشی‌ها و گالری‌های جواهر.

## امکانات

- **داشبورد**: ثبت قیمت روز طلای ۱۸ عیار، آمار فروش امروز و کل فروش، دسترسی سریع به صدور فاکتور
- **مدیریت محصولات**: ثبت انگشتر، گردن‌بند، دستبند، النگو، سکه و... با وزن، عیار، اجرت ساخت و موجودی
- **مدیریت مشتریان**: ثبت نام، تلفن، کد ملی و آدرس مشتریان
- **صدور فاکتور**: انتخاب مشتری، افزودن اقلام از محصولات یا به‌صورت دستی، محاسبه خودکار قیمت طبق فرمول رایج بازار طلا، اعمال تخفیف
- **خروجی PDF**: تولید فاکتور PDF فارسی (راست‌به‌چپ با فونت وزیرمتن) و اشتراک‌گذاری آن
- **تاریخ شمسی**: نمایش تاریخ صدور فاکتورها به هجری شمسی
- رابط کاربری کاملاً فارسی و راست‌به‌چپ با تم طلایی (روشن/تاریک)

## فرمول محاسبه قیمت

```
ارزش طلای خام = وزن × قیمت گرم ۱۸ عیار × (عیار ÷ ۱۸)
اجرت ساخت    = ارزش خام × درصد اجرت
سود فروشنده  = (ارزش خام + اجرت) × درصد سود
مالیات       = (اجرت + سود) × درصد مالیات (پیش‌فرض ۹٪ — فقط بر اجرت و سود)
مبلغ نهایی   = ارزش خام + اجرت + سود + مالیات
```

## مشخصات فنی

- Kotlin + Jetpack Compose (Material 3)
- پایگاه داده محلی Room (محصولات، مشتریان، فاکتورها، تنظیمات)
- تولید PDF با `PdfDocument` بومی اندروید (بدون وابستگی اضافی)
- Navigation Compose با پنج بخش اصلی
- حداقل اندروید ۸ (API 26)، هدف اندروید ۱۵ (API 35)

## بیلد

```bash
./gradlew :app:assembleDebug        # ساخت APK دیباگ
./gradlew :app:testDebugUnitTest    # اجرای تست‌های واحد
```

خروجی APK در مسیر `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.
