# طلا و جواهر — اپلیکیشن مدیریت فروش و صدور فاکتور

اپلیکیشن اندروید بومی (Kotlin + Jetpack Compose) برای فروشگاه‌های طلا و جواهر، با
رابط کاربری کاملاً فارسی و راست‌به‌چپ (RTL)، برای مدیریت کالا، مشتریان و صدور فاکتور فروش.

## امکانات

- **داشبورد**: نمایش و به‌روزرسانی سریع قیمت روز طلا (هر گرم ۱۸ عیار)، آمار فروش
  امروز، تعداد فاکتورها، مشتریان و کالاها، و دسترسی سریع به عملیات پرتکرار.
- **مدیریت کالاها**: ثبت کالا با نام، دسته‌بندی (انگشتر، گردنبند، دستبند، النگو، ...)،
  وزن، عیار، درصد اجرت، درصد سود، درصد مالیات و موجودی.
- **مدیریت مشتریان**: ثبت مشتریان با نام، تلفن، آدرس، کد ملی و یادداشت، به‌همراه
  جستجو.
- **صدور فاکتور**: انتخاب مشتری (یا مشتری متفرقه)، افزودن ردیف از کالاهای موجود یا
  به‌صورت دستی، محاسبه خودکار قیمت هر ردیف بر اساس فرمول متداول بازار طلای ایران،
  اعمال تخفیف، ثبت مبلغ پرداختی و مشاهدهٔ مانده حساب.
- **فاکتورهای صادرشده**: فهرست فاکتورها با وضعیت پرداخت (تسویه‌شده / جزئی /
  پرداخت‌نشده)، و صفحهٔ جزئیات هر فاکتور.
- **صدور PDF**: تولید فاکتور چاپی (PDF) با اطلاعات فروشگاه و اشتراک‌گذاری آن از
  طریق سایر اپلیکیشن‌ها (پیامک، واتس‌اپ، ایمیل، چاپگر و ...).
- **تنظیمات**: اطلاعات فروشگاه (نام، تلفن، آدرس، شماره پروانه کسب) و مقادیر
  پیش‌فرض قیمت‌گذاری (درصد اجرت، سود و مالیات).

## فرمول قیمت‌گذاری

قیمت طلا همواره بر اساس هر گرم طلای ۱۸ عیار («رایج») اعلام می‌شود. برای عیارهای
دیگر، قیمت هر گرم متناسب با نسبت عیار محاسبه می‌شود:

```
قیمت هر گرم (بر اساس عیار) = قیمت هر گرم ۱۸ عیار × (عیار / ۱۸)
ارزش پایه طلا              = وزن (گرم) × قیمت هر گرم (بر اساس عیار)
اجرت                        = ارزش پایه طلا × درصد اجرت
سود                         = (ارزش پایه طلا + اجرت) × درصد سود
مالیات بر ارزش‌افزوده        = (اجرت + سود) × درصد مالیات   ← فقط به اجرت و سود تعلق می‌گیرد
قیمت واحد                   = ارزش پایه طلا + اجرت + سود + مالیات
جمع ردیف                    = قیمت واحد × تعداد
```

این منطق در `app/src/main/java/com/miladsabagh/goldinvoice/domain/PriceCalculator.kt`
پیاده‌سازی و در `app/src/test/java/.../domain/PriceCalculatorTest.kt` با تست واحد
پوشش داده شده است.

## معماری فنی

- **زبان و UI**: Kotlin، Jetpack Compose (Material 3)، فونت فارسی Vazirmatn.
- **پایگاه‌داده**: Room (SQLite) برای کالاها، مشتریان و فاکتورها.
- **تنظیمات**: DataStore Preferences برای اطلاعات فروشگاه و مقادیر پیش‌فرض قیمت‌گذاری.
- **ناوبری**: Navigation Compose با نوار پایین (Bottom Navigation) شامل ۵ بخش اصلی.
- **صدور PDF**: `android.graphics.pdf.PdfDocument` برای تولید فاکتور چاپی و
  اشتراک‌گذاری از طریق `FileProvider`.
- **معماری**: MVVM با ViewModel و Repository به‌ازای هر حوزه (Product، Customer،
  Invoice، Settings) و تزریق وابستگی دستی از طریق کلاس `GoldInvoiceApp`.
