# اپ فروش طلا و جواهر با صدور فاکتور

یک نمونه اپلیکیشن موبایل Android-ready با Expo و React Native برای فروش طلا و جواهر، مدیریت سبد خرید و صدور فاکتور فارسی.

## قابلیت‌ها

- صفحه اصلی فارسی و راست‌به‌چپ برای فروشگاه طلا
- ثبت نام مشتری، شماره تماس و نرخ روز هر گرم طلای ۱۸ عیار
- کاتالوگ محصول شامل وزن، اجرت ساخت، سود فروشگاه و مالیات
- افزودن/حذف محصول و تغییر تعداد در سبد خرید
- صدور پیش‌نمایش فاکتور با شماره فاکتور، ریز اقلام، جمع ارزش طلا، اجرت، سود، مالیات و مبلغ قابل پرداخت
- ماژول مستقل محاسبه فاکتور همراه با تست واحد

## اجرای پروژه

```bash
npm install
npm run web
```

برای اجرای اندروید در محیطی که Android Studio/SDK و شبیه‌ساز دارد:

```bash
npm run android
```

## تست

```bash
npm test
```

## فرمول فاکتور

برای هر قلم کالا:

1. ارزش طلا = وزن × نرخ روز × تعداد
2. اجرت ساخت = ارزش طلا × درصد اجرت
3. سود فروشگاه = (ارزش طلا + اجرت) × درصد سود
4. مالیات = (اجرت + سود) × درصد مالیات
5. جمع کل = ارزش طلا + اجرت + سود + مالیات
