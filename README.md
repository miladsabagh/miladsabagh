# زرین

یک اپلیکیشن موبایل فارسی برای فروش طلا و جواهر با قابلیت ساخت و صدور فاکتور شفاف.

## امکانات

- ویترین و جستجوی محصولات با دسته‌بندی
- نمایش نرخ لحظه‌ای طلای ۱۸ عیار
- علاقه‌مندی‌ها و انتخاب محصول برای فاکتور
- محاسبه ارزش طلا، اجرت، سود و مالیات
- صدور و نگهداری فاکتور دیجیتال
- رابط راست‌چین و واکنش‌گرا برای موبایل

## اجرا

```bash
npm install
npm run dev
```

## آزمون

```bash
npm test
npm run build
```
