# آتلیه زرین

اپلیکیشن موبایل فروش طلا و جواهر با رابط فارسی و راست‌به‌چپ، ساخته‌شده با
Expo و React Native.

## امکانات

- نمایش لحظه‌ای قیمت طلا و کاتالوگ محصولات
- جست‌وجو و فیلتر بر اساس دسته‌بندی
- علاقه‌مندی‌ها، جزئیات محصول و سبد خرید
- محاسبه اجرت ساخت و مالیات اجرت
- پیش‌نمایش فاکتور و صدور یا اشتراک PDF
- رابط واکنش‌گرا برای Android و Web

## اجرا

```bash
npm install
npm run android
```

برای اجرای نسخه وب:

```bash
npm run web
```

بررسی کد و ساخت نسخه وب:

```bash
npm run typecheck
npm run build:web
```
