# زرین

اپلیکیشن موبایل فارسی و راست‌به‌چپ برای مدیریت فروش طلا و جواهر، مشاهده قیمت روز، مدیریت کاتالوگ و صدور فاکتور رسمی.

## امکانات

- داشبورد قیمت لحظه‌ای طلای ۱۸ عیار و خلاصه فروش
- کاتالوگ محصولات همراه با جست‌وجو و دسته‌بندی
- سبد فروش و مدیریت تعداد اقلام
- محاسبه اصل طلا، اجرت، سود فروشنده و مالیات
- پیش‌نمایش فاکتور و خروجی PDF/اشتراک‌گذاری
- رابط فارسی RTL با فونت وزیرمتن

## اجرا

```bash
npm install
npm run web
```

برای اجرای اندروید، Expo Go یا Android Studio را آماده کنید و سپس:

```bash
npm run android
```

## بررسی کیفیت

```bash
npm run typecheck
npm test
npm run build:web
```
