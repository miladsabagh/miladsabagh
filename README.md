# طلا و جواهر — اپ اندروید فروش و فاکتور

اپلیکیشن موبایل اندروید برای فروشگاه‌های طلا و جواهر با قابلیت مدیریت موجودی، مشتری و **صدور فاکتور PDF**.

## امکانات

- داشبورد فروش روزانه/ماهانه و نرخ روز طلا
- کاتالوگ محصولات (انگشتر، گردنبند، سکه، شمش و …)
- محاسبه قیمت بر اساس وزن، عیار، اجرت و سود
- مدیریت مشتریان
- صدور فاکتور با تخفیف، مالیات و مبلغ پرداختی
- خروجی PDF و اشتراک‌گذاری فاکتور
- رابط فارسی و راست‌چین (RTL)
- ذخیره‌سازی محلی با Room (بدون نیاز به اینترنت)

## ساختار

```
app/src/main/java/com/goldshop/app/
  data/          مدل‌ها، Room، Repository
  ui/            صفحات Compose و تم
  util/          محاسبه قیمت، فرمت فارسی، PDF
```

## پیش‌نیاز اجرا

- Android Studio Ladybug+ / Hedgehog+
- JDK 17
- Android SDK 35

## اجرا

1. پروژه را در Android Studio باز کنید.
2. Gradle Sync را انجام دهید.
3. یک امولاتور یا گوشی اندروید (API 26+) وصل کنید.
4. Run روی ماژول `app`.

```bash
./gradlew :app:assembleDebug
./gradlew :app:test
```

## منطق قیمت‌گذاری

```
قیمت پایه = وزن(گرم) × (عیار / ۷۵۰) × نرخ هر گرم طلای ۱۸
قیمت نهایی = قیمت پایه × (۱ + اجرت%) × (۱ + سود%)
```

نرخ طلا از بخش **تنظیمات** قابل تغییر است.

## مسیرهای اصلی اپ

| صفحه | کاربرد |
|------|--------|
| خانه | نرخ طلا، آمار فروش، میانبر صدور فاکتور |
| محصولات | افزودن/ویرایش کالا و افزودن به فاکتور |
| فاکتور | پیش‌نویس، صدور، سوابق، اشتراک PDF |
| مشتریان | دفترچه مشتریان |
| تنظیمات | نام فروشگاه، نرخ طلا، مالیات |
