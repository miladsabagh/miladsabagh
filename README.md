# زرنگار — اپلیکیشن فروش طلا و جواهر با صدور فاکتور

اپلیکیشن اندروید (Kotlin + Jetpack Compose) برای گالری‌های طلا و جواهر: مدیریت انبار،
مشتریان، محاسبهٔ لحظه‌ای قیمت بر اساس نرخ روز طلا، و صدور فاکتور رسمی به‌همراه
خروجی PDF و چاپ. کل رابط کاربری فارسی و راست‌چین است و تاریخ‌ها شمسی هستند.

---

## قابلیت‌ها

| بخش | توضیح |
| --- | --- |
| داشبورد | نرخ روز طلا، فروش امروز، تعداد فاکتور، وزن فروخته‌شده، مانده مطالبات، آخرین فاکتورها |
| کالاها | افزودن/ویرایش/حذف، دسته‌بندی، عیار، وزن، وزن و ارزش سنگ، اجرت، سود، موجودی، جستجو و فیلتر |
| فروش | سبد فروش، انتخاب مشتری، تعداد، تخفیف سطری و کلی، روش پرداخت، مبلغ پرداختی، ریز محاسبهٔ هر قلم |
| فاکتورها | فهرست و جستجو، فیلتر وضعیت تسویه، جزئیات کامل، ثبت پرداخت، حذف |
| خروجی فاکتور | تولید PDF در قطع A4 راست‌چین، اشتراک‌گذاری (واتساپ/ایمیل/…) و چاپ |
| مشتریان | نام، تلفن، کد ملی، نشانی |
| تنظیمات | اطلاعات سربرگ فاکتور، نرخ طلا، درصد اجرت و سود پیش‌فرض، نرخ مالیات، گرد کردن، واحد پول |

## فرمول قیمت‌گذاری

مطابق رویهٔ رایج بازار ایران، برای هر قلم:

```
نرخ هر گرم   = نرخ گرم طلای ۱۸ عیار × (عیار کالا ÷ ۷۵۰)
ارزش طلا     = (وزن کل − وزن سنگ) × نرخ هر گرم
اجرت ساخت    = ارزش طلا × درصد اجرت        (یا: مبلغ ثابت هر گرم × وزن طلا)
سود فروشنده  = (ارزش طلا + اجرت) × درصد سود
مالیات ا.ا.  = (اجرت + سود [+ ارزش سنگ]) × نرخ مالیات
قیمت نهایی   = ارزش طلا + اجرت + سود + ارزش سنگ + مالیات
```

نکته‌های مهم پیاده‌سازی‌شده:

- **ارزش طلای خام مشمول مالیات بر ارزش افزوده نیست**؛ مالیات فقط روی اجرت و سود
  (و در صورت فعال بودن تنظیم مربوطه، ارزش سنگ) محاسبه می‌شود.
- **سکه و مسکوکات** با گزینهٔ «قیمت مقطوع» و «معاف از مالیات» ثبت می‌شوند.
- **تخفیف** به نسبت بین بخش مشمول و معاف سرشکن می‌شود تا مالیات روی مبلغ واقعی
  پس از تخفیف حساب شود؛ تخفیف کلی فاکتور نیز به نسبت مبلغ هر سطر بین سطرها پخش
  می‌شود (روش «بزرگ‌ترین باقی‌مانده») تا مجموع دقیقاً برابر تخفیف واردشده بماند.
- **گرد کردن** مبلغ نهایی (بدون گرد کردن / ۱٬۰۰۰ / ۱۰٬۰۰۰ / ۱۰۰٬۰۰۰) قابل تنظیم است و
  مبلغ گرد شده به‌صورت شفاف در فاکتور نمایش داده می‌شود.

## معماری

```
app/src/main/java/com/zarnegar/gold/
├── core/            تاریخ شمسی، قالب‌بندی اعداد فارسی، عدد به حروف  (بدون وابستگی به اندروید)
├── domain/model/    مدل‌های دامنه و enumها
├── domain/pricing/  موتور محاسبهٔ قیمت (خالص و تست‌پذیر)
├── data/db/         Room: entityها، DAOها، دیتابیس
├── data/repo/       مخزن‌ها + تنظیمات روی DataStore
├── data/seed/       دادهٔ نمونهٔ اولین اجرا
├── pdf/             تولید PDF فاکتور، اشتراک‌گذاری و چاپ
└── ui/              Compose: تم، اجزای مشترک، ViewModelها و صفحه‌ها
```

- **Kotlin 2.1** + **Jetpack Compose (Material 3)**
- **Room** برای کالا/مشتری/فاکتور و **DataStore** برای تنظیمات
- **ViewModel + StateFlow**، تزریق وابستگی سبک و دستی از طریق `AppContainer`
- قلم **Vazirmatn** (مجوز SIL OFL، در `licenses/`) برای رابط کاربری و PDF
- `minSdk 26`، `targetSdk 35`

## ساخت و اجرا

```bash
# نصب روی دستگاه/شبیه‌ساز متصل
./gradlew installDebug

# ساخت فایل نصبی
./gradlew assembleDebug     # app/build/outputs/apk/debug/app-debug.apk

# اجرای تست‌های واحد
./gradlew testDebugUnitTest
```

برای ساخت، مسیر Android SDK را در `local.properties` تنظیم کنید:

```properties
sdk.dir=/path/to/Android/sdk
```

## تست‌ها

۲۶ تست واحد روی منطق حساس اجرا می‌شود:

- `GoldPricingTest` — محاسبهٔ عیار، اجرت درصدی و ثابت، سود، معافیت طلای خام از
  مالیات، سکهٔ معاف، سرشکن‌کردن تخفیف، گرد کردن و سازگاری جمع‌ها
- `JalaliDateTest` — تبدیل شمسی/میلادی (رفت‌وبرگشت روزبه‌روز در بازهٔ ده‌ساله)،
  سال کبیسه، تعداد روزهای ماه و قالب‌بندی
- `PersianTextTest` — تبدیل ارقام، جداکنندهٔ هزارگان، وزن، درصد و «عدد به حروف»
